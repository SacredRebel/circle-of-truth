# Artwork inbox

The Gallery reads images from this directory by **exact filename**, as listed in `data/content.json`.

The original artwork was generated/uploaded in the conversation and is not bundled inside this GitHub repository yet. Use the prepared artwork ZIP from the handoff, extract its `artwork/` folder into this repo, inspect the files and commit them:

```bash
git add artwork
git commit -m "assets: import reviewed Circle of Truth cast and branding artwork"
git push origin main
```

**Review before sharing:** for every 10-person sheet verify the right ten people, exact labels, no repeats, one row, and feet visible. Historical Freemasons, Hollywood II and Music IV require corrected renders before approval.

Poster rights and factual name/title/affiliation claims must be checked separately before public release.
